    도움말

    일반 저장: 게임에서 저장 → .sav 내보내기. 다시 쓸 때는 ROM → .sav 불러오기.

    T 저장 · R 복원은 실행 중에만 유지됩니다. ROM 재실행·새로고침·종료 시 삭제됩니다.

    소리와 게임 시계는 배속에 맞춰 진행됩니다. 게임을 멈추거나 닫으면 시계도 멈춥니다.

    앱 설치: Android Chrome 메뉴 / iPhone Safari 공유 → 홈 화면 추가.

    iPhone 세이브: 공유 → 파일에 저장. Android는 다운로드 폴더를 확인하세요.

    브라우저·홈 화면 앱의 보관함은 다를 수 있습니다. 옮기거나 앱 데이터를 지우기 전 .sav를 내보내세요. 외부 .sav의 게임 시계는 별도 확인하세요.

    S 목록 · E 등록 도구 · A 선택 · B 취소

    다운로드 폴더에서 ROM을 찾으세요. 목록에 없으면 모든 파일 보기에서 확장자나 파일명으로 검색하세요.

    PC: 방향키 · Z=선택 · X=취소 · S/Enter=목록 · E/Shift=등록 · T=임시 저장 · R=복원

    다운로드한 ROM을 선택하세요.
