세이브

게임 안에서 저장한 뒤 파일 저장을 눌러 휴대폰에 보관하세요.

T는 현재 화면 임시 저장, R은 복원입니다. 임시 저장은 ROM 재실행·새로고침·종료 시 지워지며, 재실행 후에는 일반 세이브로 이어갑니다.

기기 보관: 게임을 연 뒤 시작됩니다

플레이 설정

배속 플레이 중에는 소리를 끕니다. 게임 시계는 실제 시간을 따릅니다.

휴대폰 설치 · 파일 저장 안내

안드로이드: Chrome 메뉴에서 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택하세요.

아이폰: Safari에서 공유 버튼을 누르고 ‘홈 화면에 추가’를 선택하세요.

아이폰 세이브: ‘파일 저장’ 후 공유 창에서 ‘파일에 저장’ → ‘나의 iPhone’을 선택하세요. 공유가 지원되지 않으면 다운로드됩니다.

브라우저 보관과 홈 화면 앱 보관은 분리될 수 있습니다. 옮기기 전 .sav를 저장하고 새 창에서 불러오세요. 브라우저 데이터를 지우면 기기 보관본도 삭제될 수 있습니다.

외부 .sav는 게임 진행을 담지만 시계 정보가 없을 수 있습니다. 이 앱은 같은 기기의 시계 정보를 별도 보관합니다.

S: 게임 목록 · E: 게임에서 등록한 도구 사용
A: 선택 · B: 취소

PC: 방향키 · Z=A · X=B · S/Enter=목록 · E/Shift=등록 · T=임시 저장 · R=복원
