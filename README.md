# 골드 플레이어

안드로이드·아이폰·PC에서 기기의 GB/GBC 파일을 실행하는 설치형 웹앱입니다.

[플레이어 열기](https://gnfpscl2-collab.github.io/gold-mobile-player/)

## 시작하기

1. 개조 ROM을 휴대폰에 별도 저장합니다. ROM은 앱에 포함되어 있지 않습니다.
2. 플레이어에서 **ROM 파일 열기**를 눌러 .gb 또는 .gbc를 선택합니다. 압축 파일은 먼저 풀어 주세요.
3. 화면의 방향키, A/B, START/SELECT로 플레이합니다.
4. 게임 안에서 저장한 뒤 앱의 **파일 저장 .sav**를 눌러 휴대폰에도 보관합니다.
5. 기존 진행은 ROM을 먼저 열고 **불러오기 .sav**로 가져옵니다. 불러오면 게임이 재시작됩니다.

## 휴대폰에 설치하기

- **안드로이드:** Chrome에서 링크를 열고 메뉴의 앱 설치 또는 홈 화면에 추가를 선택합니다. .sav는 다운로드 폴더에 저장됩니다.
- **아이폰:** Safari에서 링크를 열고 공유 → 홈 화면에 추가를 선택합니다. .sav 저장 때 공유 창이 뜨면 파일에 저장 → 나의 iPhone을 선택합니다. 공유가 지원되지 않으면 다운로드됩니다.
- 처음 온라인으로 앱을 연 뒤에는 앱 파일이 오프라인에 보관됩니다. 마지막 ROM과 세이브도 같은 브라우저의 기기 보관함에서 다시 열 수 있습니다.
- 홈 화면 앱과 일반 브라우저의 보관함은 다를 수 있습니다. 옮기기 전에 .sav를 내보내고 새 앱에서 불러오세요.

## 배속과 조작

휴대폰·태블릿은 1~5배속, PC는 최대 10배속을 선택할 수 있습니다. 실제 도달 속도는 기기 성능에 따라 달라집니다. 배속 중 소리는 꺼집니다. 1배속에서 소리 켜기를 선택하면 됩니다.

PC 키보드: 방향키, Z=A, X=B, Enter=START, Shift=SELECT. 터치 조작은 여러 버튼을 동시에 누를 수 있고, 앱을 떠나면 자동으로 일시정지합니다.

RTC는 배속과 관계없이 기기의 실제 시간을 따릅니다. 시계와 배터리 세이브를 기기 보관함에 함께 보관하므로 같은 브라우저에서 다시 열 때 경과 시간이 반영됩니다.

## 파일과 저장

- ROM: .gb, .gbc. 헤더·용량·체크섬·지원 카트리지를 검사합니다. 최대 8MiB입니다.
- 세이브: 일반 배터리 .sav. 한국어판 금은 32,768바이트입니다. .state·.srm·ZIP·RTC 추가 데이터가 붙은 형식은 자동 변환하지 않습니다.
- .sav는 게임 안에서 저장한 진행입니다. 현재 화면을 그대로 복원하는 순간 저장 파일은 지원하지 않습니다.
- 외부 .sav에는 RTC가 없을 수 있습니다. 다른 에뮬레이터에서 옮기면 게임 시계는 별도 확인하세요. 이 앱의 RTC 정보는 같은 기기의 브라우저에 보관됩니다.
- ROM과 세이브는 서버로 업로드되지 않습니다. GitHub에는 플레이어 소스만 있습니다.
- 브라우저 데이터 삭제·앱 삭제·저장소 정리로 기기 보관함이 사라질 수 있으므로 .sav를 따로 보관하세요. 저장 읽기/쓰기 실패 시 기존 게임을 빈 세이브로 교체하지 않습니다.

## 개발과 검증

정적 파일 앱이며 빌드 의존성이 없습니다. Node.js에서 아래 명령으로 자동 검사를 실행합니다.

    npm test

로컬 서버 예시:

    python -m http.server 8787 --bind 127.0.0.1

http://127.0.0.1:8787/ 에서 확인합니다. PWA 설치·오프라인 보관은 HTTPS 또는 localhost에서 동작합니다.

파일 검증·모바일 속도 제한·오디오·저장 장애 및 동시 불러오기 자동 검사 12건이 통과했습니다. 실제 개조 ROM으로 한글 메뉴, 터치 START, 기기 보관 복원, 32KiB .sav 다운로드 및 재불러오기를 데스크톱 브라우저에서 확인했습니다. 390×844와 844×390 배치도 검사했습니다. 안드로이드·아이폰 실기 성능과 소리 출력은 아직 직접 검사하지 않았습니다.

## 코어

[GameBoy-Online](https://github.com/taisel/GameBoy-Online)의 MIT 코어를 고정 커밋으로 포함합니다. 원본 라이선스와 출처는 vendor/ 폴더에 있습니다. 코어는 실제 개조 ROM의 CGB/MBC3 실행, SRAM 왕복, 5배속에서도 독립적인 RTC와 오프라인 시계 복원을 별도 검사했습니다. 게임 ROM·부팅 BIOS는 포함하지 않습니다.
