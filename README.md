# Pokemon

안드로이드·아이폰·PC에서 기기의 GB/GBC 파일을 실행하는 설치형 웹앱입니다.

[플레이어 열기](https://gnfpscl2-collab.github.io/gold-mobile-player/)

## 시작하기

1. 플레이어의 **목록 아이콘 → Drive에서 다운로드**를 눌러 `Pokemon gold(K).gbc`를 기기에 저장하세요.
2. **ROM 파일 찾기**를 눌러 다운로드 폴더에서 .gb 또는 .gbc를 선택하세요. 여러 ROM을 고르면 실행할 파일 목록이 나옵니다. 파일이 보이지 않으면 **모든 파일 보기**에서 파일명이나 확장자로 찾으세요.
3. 방향키와 A(왼쪽, 선택)·B(오른쪽, 취소)로 플레이합니다. S는 게임 목록, E는 게임에서 등록한 도구를 사용합니다.
4. 게임 안에서 저장한 뒤 **목록 아이콘 → 내보내기 .sav**를 눌러 휴대폰에도 보관합니다.
5. 기존 진행은 ROM을 먼저 열고 **목록 아이콘 → 불러오기 .sav**로 가져옵니다. 불러오면 게임이 재시작됩니다.

## 휴대폰에 설치하기

- **안드로이드:** Chrome에서 링크를 열고 메뉴의 앱 설치 또는 홈 화면에 추가를 선택합니다. .sav는 다운로드 폴더에 저장됩니다.
- **아이폰:** Safari에서 링크를 열고 공유 → 홈 화면에 추가를 선택합니다. .sav 저장 때 공유 창이 뜨면 파일에 저장 → 나의 iPhone을 선택합니다. 공유가 지원되지 않으면 다운로드됩니다.
- 처음 온라인으로 앱을 연 뒤에는 앱 파일이 오프라인에 보관됩니다. 마지막 ROM과 세이브도 같은 브라우저의 기기 보관함에서 다시 열 수 있습니다.
- 홈 화면 앱과 일반 브라우저의 보관함은 다를 수 있습니다. 옮기기 전에 .sav를 내보내고 새 앱에서 불러오세요.

## 배속과 조작

메뉴를 열면 게임이 일시정지하고 닫으면 이어집니다. 메뉴의 화면 크기를 80·90·100%로 조절할 수 있습니다. 파일·세이브·속도·소리 설정은 메뉴에 모았습니다.

휴대폰·태블릿은 1~5배속, PC는 최대 10배속을 선택할 수 있습니다. 실제 도달 속도는 기기 성능에 따라 달라집니다. 소리는 선택한 배속에 맞춰 재생되며 메뉴의 소리 설정이 기기에 저장됩니다.

PC 키보드: 방향키, Z=A, X=B, S/Enter=게임 목록(START), E/Shift=등록 도구(SELECT), T=현재 화면 임시 저장, R=복원. 터치 조작은 여러 버튼을 동시에 누를 수 있고, 앱을 떠나면 자동으로 일시정지합니다.

RTC는 배속과 관계없이 기기의 실제 시간을 따릅니다. 시계와 배터리 세이브를 기기 보관함에 함께 보관하므로 같은 브라우저에서 다시 열 때 경과 시간이 반영됩니다.

## 파일과 저장

- ROM: .gb, .gbc. 헤더·용량·체크섬·지원 카트리지를 검사합니다. 최대 8MiB입니다.
- 세이브: 일반 배터리 .sav. 한국어판 금은 32,768바이트입니다. .state·.srm·ZIP·RTC 추가 데이터가 붙은 형식은 자동 변환하지 않습니다.
- .sav는 게임 안에서 저장한 진행입니다. T/R 임시 화면 저장과 별개입니다. T/R은 현재 실행 중인 메모리에서만 동작하며 .sav 파일이 아닙니다.
- 외부 .sav에는 RTC가 없을 수 있습니다. 다른 에뮬레이터에서 옮기면 게임 시계는 별도 확인하세요. 이 앱의 RTC 정보는 같은 기기의 브라우저에 보관됩니다.
- 지정한 개조 ROM은 Drive에서 기기에 다운로드한 뒤 플레이어에서 선택합니다. GitHub에는 플레이어 소스만 있으며 ROM은 포함하지 않습니다. 플레이어가 기기 ROM이나 세이브를 서버로 업로드하지는 않습니다.
- 브라우저 데이터 삭제·앱 삭제·저장소 정리로 기기 보관함이 사라질 수 있으므로 .sav를 따로 보관하세요. 저장 읽기/쓰기 실패 시 기존 게임을 빈 세이브로 교체하지 않습니다.

## 채팅

상단 메뉴 왼쪽의 **로그인**에서 Gmail 또는 네이버 이메일로 가입하세요. 별도 메일 인증 창에서 인증을 확인한 뒤 닉네임을 등록하면 하단 채팅을 이용할 수 있습니다. 닉네임은 한글 6자 또는 영문 12자까지 등록할 수 있습니다. 혼용하면 한글 1자를 영문 2자로 계산합니다. 영문 대소문자가 달라도 같은 이름으로 취급하며, 계정당 한 번 등록합니다.

채팅은 최근 메시지 100개를 보관합니다. 전송 간격은 기본 3초이며 10초 안에 세 번 보내면 세 번째 메시지 이후 15초 동안 새 메시지를 보낼 수 없습니다. **온라인**에서 최근 100초 내에 접속이 확인된 닉네임을 볼 수 있습니다. 배포한 한국어 개조판의 포켓몬센터 2층에서 교환을 선택하면 이 목록이 펼쳐집니다. 운영 설정은 [채팅 설정 안내](./CHAT_SETUP.md)에 있습니다.

## 개발과 검증

정적 파일 앱이며 빌드 의존성이 없습니다. Node.js에서 아래 명령으로 자동 검사를 실행합니다.

    npm test

로컬 서버 예시:

    python -m http.server 8787 --bind 127.0.0.1

http://127.0.0.1:8787/ 에서 확인합니다. PWA 설치·오프라인 보관은 HTTPS 또는 localhost에서 동작합니다.

파일 검증·모바일 속도 제한·오디오·저장 장애 및 동시 불러오기 자동 검사 41건이 통과했습니다. 실제 개조 ROM으로 한글 메뉴, 터치 START, 기기 보관 복원, 32KiB .sav 다운로드 및 재불러오기를 데스크톱 브라우저에서 확인했습니다. 320×700·390×844·844×390 배치, 메뉴 정지·재개, S/E 입력과 화면 크기 복원도 검사했습니다. 안드로이드·아이폰 실기 성능과 소리 출력은 아직 직접 검사하지 않았습니다.

## 코어

[GameBoy-Online](https://github.com/taisel/GameBoy-Online)의 MIT 코어를 고정 커밋으로 포함합니다. 원본 라이선스와 출처는 vendor/ 폴더에 있습니다. 코어는 실제 개조 ROM의 CGB/MBC3 실행, SRAM 왕복, 5배속에서도 독립적인 RTC와 오프라인 시계 복원을 별도 검사했습니다. 게임 ROM·부팅 BIOS는 포함하지 않습니다.

S는 게임 원래의 START, E는 SELECT 입력입니다. E는 가방에서 미리 등록한 자전거·낚싯대 등 도구를 사용하며 게임 상황에 따라 동작합니다.

제목 글꼴은 [Google Fonts의 Silkscreen Bold](https://github.com/google/fonts/tree/main/ofl/silkscreen)를 앱에 포함했습니다. SIL Open Font License 원문은 LICENSE.Silkscreen.txt에 있습니다.

## 다운로드한 ROM과 세이브

기기의 다운로드 폴더에서 ROM을 찾으세요. iPhone에서는 파일 앱의 둘러보기에서 다운로드 위치를 확인할 수 있습니다. 같은 내용의 ROM은 파일명이 달라도 저장 데이터에 연결됩니다. 내용이 다른 개조본에는 기존 .sav를 직접 가져올 수 있습니다.

## T/R 임시 저장

A·B·S·E·T·R은 색이 다른 원형 버튼입니다. T는 현재 CPU·메모리·화면을 임시 슬롯1개에 보관하고 저장 시각을 표시합니다. 다시 T를 누르면 이전 임시 슬롯을 바꿉니다. R은 해당 시점으로 돌아오며 반복해서 사용할 수 있습니다. 임시 슬롯을 파일·IndexedDB·Drive에 저장하지 않습니다. ROM을 다시 열거나 바꾸기, 일반 .sav 불러오기로 게임 재시작, 페이지 새로고침·탐색·종료 시 지워집니다. 단순히 앱을 잠깐 가리는 동안에는 유지합니다. 종료 후에는 일반 게임 세이브로 이어갑니다. 계속할 진행은 종료 전에 게임 안에서 저장하고 필요하면 .sav도 내보내세요. R은 진행과 SRAM도 해당 시점으로 되돌리며, 게임 시계는 실제 경과 시간을 반영합니다.

## 화면 크기와 배치

원본160×144 비율을 유지하며 창 크기에 따라 게임 표시 영역을 조절합니다. 화면100% 기준:390×844 휴대폰은320×288,768×1024·884×1104 펼친 화면은640×576,1366×768 PC는640×576,1920×1080 PC는800×720입니다. 창이 짧거나 좁으면 비율을 유지해 맞춥니다. 큰 PC 창은 게임 옆으로 조작부를 옮기고, 메뉴의 ROM·세이브 버튼은24px 높이·10px 글자로, 화면·속도 선택칸은63×24px 표시 크기로 줄였습니다. 메뉴 폭은260px입니다.
