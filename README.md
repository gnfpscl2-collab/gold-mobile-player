# Pokemon

안드로이드·아이폰·PC에서 기기의 GB/GBC 파일을 실행하는 설치형 웹앱입니다.

[플레이어 열기](https://gnfpscl2-collab.github.io/gold-mobile-player/)

## 시작하기

1. 메뉴의 **GitHub에서 다운로드**로 `pokemon_gold_ko_v0_8.gbc`를 기기에 저장하세요.
2. **ROM 파일 찾기**를 눌러 다운로드 폴더에서 .gb 또는 .gbc를 선택하세요. 여러 ROM을 고르면 실행할 파일 목록이 나옵니다. 파일이 보이지 않으면 **모든 파일 보기**에서 파일명이나 확장자로 찾으세요.
3. 방향키와 Z(왼쪽, 선택)·X(오른쪽, 취소)로 플레이합니다. S는 게임 목록, E는 게임에서 등록한 도구를 사용합니다.
4. 게임 안에서 저장한 뒤 **목록 아이콘 → 내보내기 .sav**를 눌러 휴대폰에도 보관합니다.
5. 기존 진행은 ROM을 먼저 열고 **목록 아이콘 → 불러오기 .sav**로 가져옵니다. 불러오면 게임이 재시작됩니다.

## 휴대폰에 설치하기

- **안드로이드:** Chrome에서 링크를 열고 메뉴의 앱 설치 또는 홈 화면에 추가를 선택합니다. .sav는 다운로드 폴더에 저장됩니다.
- **아이폰:** Safari에서 링크를 열고 공유 → 홈 화면에 추가를 선택합니다. .sav 저장 때 공유 창이 뜨면 파일에 저장 → 나의 iPhone을 선택합니다. 공유가 지원되지 않으면 다운로드됩니다.
- 처음 온라인으로 앱을 연 뒤에는 앱 파일이 오프라인에 보관됩니다. 마지막 ROM과 세이브도 같은 브라우저의 기기 보관함에서 다시 열 수 있습니다.
- 홈 화면 앱과 일반 브라우저의 보관함은 다를 수 있습니다. 옮기기 전에 .sav를 내보내고 새 앱에서 불러오세요.

## 배속과 조작

메뉴를 열면 게임이 일시정지하고 닫으면 이어집니다. 메뉴의 화면 크기를 80·90·100%로 조절할 수 있습니다. 파일·세이브·속도·소리 설정은 메뉴에 모았습니다.

휴대폰·태블릿은 1~5배속, PC는 최대 10배속을 선택할 수 있습니다. 실제 도달 속도는 기기 성능에 따라 달라집니다. 소리는 선택한 배속에 맞춰 재생되며 메뉴의 소리 설정이 기기에 저장됩니다.

PC 키보드는 방향키, Z(선택), X(취소), S/Enter(게임 목록), E/Shift(등록 도구), T(현재 화면 임시 저장), R(복원)을 사용합니다. 터치 조작은 여러 버튼을 동시에 누를 수 있고, 앱을 떠나면 자동으로 일시정지합니다.

게임 시계는 에뮬레이터가 실행한 시간만큼 흐릅니다. 5배속으로 게임이 5초 진행되면 시계도 5초 앞섭니다. 일시정지하거나 플레이어를 닫으면 멈추며, 같은 브라우저에서 다시 열면 마지막으로 보관한 게임 시각부터 이어집니다.

개조판에서 은빛산 레드를 격파하면 게임 속 수요일 18:00부터 목요일 03:59까지 너도밤나무숲 사당에서 레벨 90 세레비와 한 번 조우할 수 있습니다. 포획에 실패하거나, 도망치거나, 세레비가 기절해도 다시 등장하지 않습니다.

v0.2에서는 엔테이·스이쿤·라이코우를 선두 포켓몬의 레벨과 관계없이 만날 수 있습니다. 스프레이 사용 중에도 세 마리의 출현 여부는 기존 해금·이동·확률 조건을 따릅니다. 조우 레벨은 40이고 전투 중 도주 조건도 기존과 같습니다.

## 게임장 1대1 대결

금빛시티와 무지개시티 게임장의 대결 NPC에게 말을 걸어 1대1로 대결합니다. 동전 케이스가 필요하며, 내 쪽은 전투 가능한 파티원 중 레벨이 가장 높은 한 마리가 참가합니다. 게임장에 다시 들어가면 상대를 다시 뽑습니다.

| 게임장 | 상대 레벨 | 참가비 | 승리 배율 | 승리 시 지급 |
| --- | ---: | ---: | --- | --- |
| 금빛시티 | 20 | 200코인 | 2배·4배·8배 | 400·800·1,600코인 |
| 무지개시티 | 50 | 500코인 | 4배·8배·12배 | 2,000·4,000·6,000코인 |

패배하면 참가비를 잃고 무승부면 돌려받습니다. 배율에 따라 상대 포켓몬이 달라지며, 대결 후 기존 파티가 복원됩니다.

## 반짝이는 야생 포켓몬

게임 시계에서 매시간 0~59분 중 한 분을 무작위로 정합니다. 그 시각 이후 성립하는 첫 일반 야생 전투에서 현재 맵과 시간의 출현표로 고른 포켓몬이 반짝이는 모습으로 나옵니다. 조우하지 않은 시간의 기회는 지나갑니다. 그 시간에 한 번 만났다면 다음 시간에 새로 추첨하며, 사용 기록은 일반 게임 세이브에 함께 저장됩니다.

## 파일과 저장

- ROM: .gb, .gbc. 헤더·용량·체크섬·지원 카트리지를 검사합니다. 최대 8MiB입니다.
- 세이브: 일반 배터리 .sav. 한국어판 금은 32,768바이트입니다. .state·.srm·ZIP·RTC 추가 데이터가 붙은 형식은 자동 변환하지 않습니다.
- .sav는 게임 안에서 저장한 진행입니다. T/R 임시 화면 저장과 별개입니다. T/R은 현재 실행 중인 메모리에서만 동작하며 .sav 파일이 아닙니다.
- 같은 브라우저에서 새 개조판을 처음 열면 보관된 이전 판의 세이브와 게임 시각을 복사합니다. 각 버전의 진행은 이후 별도로 저장됩니다.
- 외부 .sav에는 RTC가 없을 수 있습니다. 다른 에뮬레이터에서 옮기면 게임 시계는 별도 확인하세요. 이 앱의 RTC 정보는 같은 기기의 브라우저에 보관됩니다.
- 개조 ROM은 GitHub 릴리스에서 내려받습니다. 플레이어가 기기에서 선택한 ROM과 세이브는 로컬에서 사용합니다.
- **메뉴 → 공략집**에서 도시별 진행과 NPC 보상을 찾아볼 수 있습니다. **TXT 저장**으로 같은 문서를 내려받을 수 있습니다.
- 브라우저 데이터 삭제·앱 삭제·저장소 정리로 기기 보관함이 사라질 수 있으므로 .sav를 따로 보관하세요. 저장 읽기/쓰기 실패 시 기존 게임을 빈 세이브로 교체하지 않습니다.

## 채팅

상단 메뉴 왼쪽의 **로그인**에서 Gmail 또는 네이버 이메일로 가입하세요. 별도 메일 인증 창에서 인증을 확인한 뒤 닉네임을 등록하면 하단 채팅을 이용할 수 있습니다. 닉네임은 한글 6자 또는 영문 12자까지 등록할 수 있습니다. 혼용하면 한글 1자를 영문 2자로 계산합니다. 영문 대소문자가 달라도 같은 이름으로 취급하며, 계정당 한 번 등록합니다.

채팅은 최근 메시지 100개를 보관합니다. 전송 간격은 기본 3초이며 10초 안에 세 번 보내면 세 번째 메시지 이후 15초 동안 새 메시지를 보낼 수 없습니다. **온라인**에서 최근 100초 내에 접속이 확인된 닉네임을 볼 수 있습니다. 운영 설정은 [채팅 설정 안내](./CHAT_SETUP.md)에 있습니다.

## 통신교환

1. 두 사람 모두 웹 플레이어에 로그인하고 같은 골드 개조판을 실행합니다. v0.1부터 v0.8까지 지원하며, SHA-256으로 ROM 내용 일치를 확인합니다.
2. 둘 다 포켓몬센터 2층에서 교환을 선택하세요. 한 사람이 목록에서 상대 닉네임을 선택하고 상대가 **수락**을 누르면 게임 화면에서 연결을 계속합니다.
3. 교환실 양쪽에서 교환 기기를 조사하고 교환할 포켓몬을 선택합니다. 게임이 교환 후 저장을 마친 뒤 기기 보관함에 반영됩니다.

교환 중에는 페이지를 열어 두세요. 교환을 마치고 저장하면 이전 T 임시 저장은 지워집니다. 두 브라우저가 직접 연결되는 네트워크에서 교환할 수 있습니다.

## 개발과 검증

정적 파일 앱이며 빌드 의존성이 없습니다. Node.js에서 아래 명령으로 자동 검사를 실행합니다.

    npm test

로컬 서버 예시:

    python -m http.server 8787 --bind 127.0.0.1

http://127.0.0.1:8787/ 에서 확인합니다. PWA 설치·오프라인 보관은 HTTPS 또는 localhost에서 동작합니다.

파일 검증, 모바일 속도 제한, RTC, 교환용 ROM 목록 일치, 오디오, 저장 및 재불러오기 자동 검사 60건이 통과했습니다. 실제 개조 ROM으로 한글 메뉴, 터치 START, 기기 보관 복원, 32KiB .sav 다운로드 및 재불러오기를 데스크톱 브라우저에서 확인했습니다. 320×700·390×844·844×390 배치, 메뉴 정지·재개, S/E 입력과 화면 크기 복원도 검사했습니다.

## 코어

[GameBoy-Online](https://github.com/taisel/GameBoy-Online)의 MIT 코어를 포함합니다. 원본 라이선스와 출처는 vendor/ 폴더에 있습니다. 실제 개조 ROM에서 CGB/MBC3 실행, SRAM 왕복, 게임 시계로 사당의 조우 시작·종료 시각을 판정하는 동작을 검사했습니다.

S는 게임 원래의 START, E는 SELECT 입력입니다. E는 가방에서 미리 등록한 자전거·낚싯대 등 도구를 사용하며 게임 상황에 따라 동작합니다.

제목 글꼴은 [Google Fonts의 Silkscreen Bold](https://github.com/google/fonts/tree/main/ofl/silkscreen)를 앱에 포함했습니다. SIL Open Font License 원문은 LICENSE.Silkscreen.txt에 있습니다.

## 다운로드한 ROM과 세이브

기기의 다운로드 폴더에서 ROM을 찾으세요. iPhone에서는 파일 앱의 둘러보기에서 다운로드 위치를 확인할 수 있습니다. 같은 내용의 ROM은 파일명이 달라도 저장 데이터에 연결됩니다. 내용이 다른 개조본에는 기존 .sav를 직접 가져올 수 있습니다.

## T/R 임시 저장

Z·X·S·E·T·R은 색이 다른 원형 버튼입니다. T는 현재 CPU·메모리·화면을 임시 슬롯 1개에 보관하고 저장 시각을 표시합니다. 다시 T를 누르면 이전 임시 슬롯을 바꿉니다. R은 진행, SRAM, 게임 시계를 해당 시점으로 되돌립니다. 임시 슬롯은 페이지를 닫거나 새로고침할 때, ROM을 다시 열거나 .sav를 가져올 때 지워집니다. 종료 후에는 일반 게임 세이브로 이어갑니다.

## 화면 크기와 배치

원본160×144 비율을 유지하며 창 크기에 따라 게임 표시 영역을 조절합니다. 화면100% 기준:390×844 휴대폰은320×288,768×1024·884×1104 펼친 화면은640×576,1366×768 PC는640×576,1920×1080 PC는800×720입니다. 창이 짧거나 좁으면 비율을 유지해 맞춥니다. 큰 PC 창은 게임 옆으로 조작부를 옮기고, 메뉴의 ROM·세이브 버튼은24px 높이·10px 글자로, 화면·속도 선택칸은63×24px 표시 크기로 줄였습니다. 메뉴 폭은260px입니다.
